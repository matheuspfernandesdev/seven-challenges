# seven-challenges (7 Challenges)

## Visão Geral

Projeto em **TypeScript** chamado **7 Challenges**, cujo objetivo é implementar e demonstrar, na prática, sete conceitos importantes de arquitetura e desenvolvimento de sistemas.

## Os Sete Desafios

1. Consistent Hashing
2. Leader Election
3. Write-Ahead Log (WAL)
4. Change Data Capture (CDC)
5. Bulkhead Pattern
6. Tail Latency — P95 e P99
7. API Pagination — Offset vs. Cursor

## Objetivo

Criar exemplos práticos de cada conceito, permitindo compreender não apenas sua implementação, mas também seu impacto em sistemas reais.

Sempre que fizer sentido, cada desafio deve possuir uma interface web simples para demonstrar visualmente seu funcionamento e permitir comparar comportamentos e resultados.

Por exemplo, no desafio de **API Pagination**, criar uma demonstração comparando paginação por **Offset** e **Cursor**, mostrando as diferenças de implementação e, principalmente, de performance.

## A Ideia é Combinar

- Exemplos práticos de código.
- APIs funcionais.
- Interface web para demonstração.
- Comparações de performance.
- Métricas e resultados observáveis.

## Status

Projeto recém-criado. Documentação de ideação (IDM) inicial. O projeto deve funcionar como um laboratório prático para demonstrar como esses conceitos impactam arquitetura, performance, escalabilidade e desenvolvimento de sistemas. Implementação ainda não iniciada.
